# Datasets Used in This Research

## 1. AT&T (ORL) Face Database
- 40 subjects, 400 images (10 per subject)
- Image size: 92x112 pixels, grayscale
- Download: https://www.kaggle.com/datasets/kasikrit/att-database-of-faces
- Place in: datasets/att_faces/

## 2. Extended Yale-B Face Database
- 38 subjects, 2,414 images
- Various lighting conditions
- Download: https://www.kaggle.com/datasets/olgabelitskaya/yale-face-database
- Place in: datasets/yale_b/

## 3. LFW Restricted (Labeled Faces in the Wild)
- 236 subjects, 19,038 images
- Real-world face images
- Download: http://vis-www.cs.umass.edu/lfw/
- Place in: datasets/lfw/

## Total
- 314 unique identities
- 21,852 images across all datasets
